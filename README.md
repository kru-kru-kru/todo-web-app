## **Project Overview**
At this stage, the To-Do List Web App allows users to:
- **Add tasks**, **display them dynamically**, and **mark completion using checkboxes**.
- **Edit** and **delete** tasks easily.
- View a **progress tracking UI** that shows completed vs. total tasks.
  
Next, it will store data using **localStorage** so tasks remain after refreshing the page.

---

## **Current Progress Documentation**

###  **Features Working So Far**
- Add new tasks (Create)  
- Display task list dynamically (Read)  
- Checkbox for marking completion (UI + visual toggle)  
- Edit and delete buttons (Update & Delete)  
- Responsive progress bar and task counter (UI only)  

###  **Features Still in Progress**
- Saving and retrieving tasks using **localStorage**  
- Automatic progress tracking update (completed vs total)  
- Input validation (prevent empty submissions)
