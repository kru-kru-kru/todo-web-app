****Project Type:** **Web Application

**Tools Used:** HTML, CSS, JavaScript

**Project Overview**

At this stage of development, the app can already create tasks, display them in a list, and toggle their completion status through check-boxes.
The edit and delete buttons are present but not yet functional.

**Current Progress Documentation:**

**Features Working So Far**

    • Add new tasks (Create)
    
    • Display task list dynamically (Read)
    
    • Checkbox for marking completion (UI only)
    
    
**Features Still in Progress**

    • Edit task functionality
    
    • Delete task functionality
    
    • Saving and retrieving tasks using localStorage
    
    • Progress tracking (completed vs total tasks)
    
    • Input validation (prevent empty submissions)
